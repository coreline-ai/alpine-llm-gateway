# implement_20260801_093437.md

작성 일시: `2026-08-01 09:34:37 KST`

이 문서는 삼성폰 실제 Provider 10턴 QA에서 확인한 다음 개선 범위를 고정하고, 구현이 완전한 Markdown 엔진이나 실행형 agent 범위로 확장되지 않도록 하기 위한 작업 문서다.

## 개발 목적

assistant 응답의 Markdown을 모바일 채팅에서 읽기 쉽게 표시하고, 사용자가 명시한 단어 수·문장 수·목록 수 같은 측정 가능한 응답 제약을 요청 전에 강화하고 완료 후 검증한다. 1차 응답이 제약을 위반하면 같은 Provider·모델·스킬·페르소나로 최대 1회 자동 교정한다. QA에서 확인한 읽기 전용 명령과 코드 계약 관련 지침도 기본 스킬 prompt에 반영한다.

## 개발 범위

- assistant 메시지에 한정해 안전한 Compose Markdown block/inline 렌더링을 제공한다.
- 제목, 문단, 순서/비순서 목록, 인용, fenced code block, 굵게, 기울임, inline code를 지원한다.
- HTML, 이미지와 임의 네트워크 리소스는 해석하거나 로드하지 않는다.
- streaming 중 닫히지 않은 Markdown marker와 code fence를 예외 없이 표시한다.
- 영어·한국어 prompt에서 숫자로 측정 가능한 단어 수 상한, 정확한 문장 수와 정확한 bullet 수를 보수적으로 감지한다.
- 감지된 제약을 bounded system instruction에 추가하고 완료 응답을 로컬에서 검증한다.
- 위반 시 기존 assistant bubble을 같은 요청의 교정 응답으로 최대 1회 교체한다.
- 2차 응답도 위반하면 응답은 보존하고 사용자에게 안전한 형식 경고만 표시한다.
- 현재 Provider·모델·Assistant mode metadata, retry, stop, 멀티 대화와 암호화 저장 계약을 유지한다.
- QA에서 확인한 비파괴 명령, shell placeholder, 코드 반환/오류 계약 지침을 catalog/core prompt에 추가한다.

## 제외 범위

- CommonMark/GFM 전체 호환, Markdown table·수식·각주·task list·syntax highlighting
- assistant 응답의 HTML 렌더링, WebView, 원격 이미지 자동 로드와 임의 링크 자동 실행
- 의미·사실 정확성의 자동 판정 또는 외부 웹 검색
- 사용자 메시지와 오류 메시지의 Markdown 렌더링
- 측정할 수 없는 주관적 요청의 자동 교정
- 2회 이상 자동 재생성, 별도 모델 judge, hidden chain-of-thought 저장
- 실제 429·5xx·비정상 SSE 계정 E2E와 Alpine 완전 통합 패키징
