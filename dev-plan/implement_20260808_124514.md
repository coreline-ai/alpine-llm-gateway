작성 일시: `2026-08-08 12:45:14 KST`

## 목적

Alpine 작업 모드의 allowlist package UI가 설치 실행과 별개로 라이선스, 예상 download/installed payload, network 필요 여부를 설명하도록 보강한다. 실제 `apk` dependency solver 또는 repository transaction 결과를 정적인 화면 정보로 오인하지 않게 한다.

## 범위와 경계

- `:alpine-runtime-api`에 재사용 가능한 display-only package metadata/catalog/estimate 계약을 추가한다.
- `:alpine-runtime-ui-compose`는 선택·승인 직전에 snapshot, license, package archive/payload 합계와 한계를 표시한다.
- `:integrated-app`은 bundled Alpine `v3.21`/`aarch64` 공식 `APKINDEX`의 확인일 snapshot을 공급한다.
- metadata catalog는 install 권한이나 `apk` argv 생성에 사용하지 않는다. 기존 exact allowlist·사용자 승인·고정 argv 정책은 변경하지 않는다.

## 제외 범위

- 실제 device repository preflight, 의존성 해석, index/cache download, disk-full, cancel, 실제 install/remove/update Samsung matrix
- allowlist 외 package 검색 또는 whole-system upgrade
- public 배포·Provider 계정·Play Track 검증

## 작업

- [x] 공식 Alpine `v3.21/main|community/aarch64/APKINDEX.tar.gz`에서 현재 exact allowlist의 version/license/S/I 값을 확인했다.
- [x] `RuntimePackageMetadata`, `RuntimePackageCatalog`, `RuntimePackageEstimate`를 Runtime API에 추가하고 중복·invalid URL·unknown package 회귀를 작성했다.
- [x] 선택 package와 승인 dialog에 resolved provider, license, download/installed payload 합계, network와 dependency/index/cache/filesystem 제외 문구를 표시했다.
- [x] `openssh-client` virtual selection이 snapshot에서는 `openssh-client-default` provider를 의미함을 표시했다.
- [x] Compose instrumentation으로 license·snapshot·의존성 제외 문구가 승인 전 표시되는지 검증했다.
