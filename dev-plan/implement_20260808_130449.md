## 목적

Alpine terminal session이 종료된 뒤에도 사용자가 종료 결과를 확인하고 새 세션을 열 수 있게 한다. Runtime public terminal I/O 계약을 넓히거나 guest 출력·명령 내용을 기록하지 않고, process exit code만 bounded host state와 Compose UI에 전달한다.

## 범위와 경계

- `:alpine-runtime-android`은 terminal process가 닫힐 때 safe terminal ID와 numeric exit code만 Runtime event attribute로 전달한다.
- `:alpine-runtime-host`는 해당 terminal이 사라진 뒤에도 마지막 종료 요약 하나만 보관한다.
- `:alpine-runtime-ui-compose`는 종료 상태를 읽을 수 있게 표시하고, 사용자가 명시적으로 새 session을 열게 한다.
- exit code는 prompt, output, guest PID, command, credential을 포함하지 않는다.

## 제외 범위

- PRoot guest dynamic resize 해결, full-screen TUI/vi/nano/top 인증, Android DocumentsUI 수동 E2E
- terminal process의 영구 history·재접속·background replay, guest log 저장
- reboot/Doze와 실제 Provider/Play 배포 검증

## 작업

- [x] terminal close callback에서 process 종료 code를 capture하고 event에 safe metadata만 전달한다.
- [x] Host controller가 terminal 제거 전 title/exit code를 마지막 종료 상태로 projection한다.
- [x] Compose terminal panel에 종료 상태 접근성 문구와 새 세션 안내를 추가한다.
- [x] Android/Host/Compose 회귀, Samsung instrumentation, 최종 APK cold start와 정적 검증을 실행했다.
