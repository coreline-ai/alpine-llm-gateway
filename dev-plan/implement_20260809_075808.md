# implement_20260809_075808.md

작성 일시: `2026-08-09 07:58:08 KST`

이 문서는 terminal key·tablet regression 수정본이 포함된 최신 통합 APK를 Samsung 제품 상태에
반영하고, credential-free 기본 화면과 최종 package 정리를 확인하기 위한 작업 문서다.

## 개발 목적

최신 `integrated-app` debug APK가 Samsung에서 실제로 설치·cold start되는지 확인하고, 테스트·Probe·Demo
package를 남기지 않은 상태에서 안전한 기본 UI를 시각 점검한다.

## 개발 범위

- 최신 debug APK를 Samsung에 재설치하고 `IntegratedMainActivity` cold start를 확인한다.
- final device의 관련 package 목록에서 integrated product만 남는지 확인한다.
- Provider credential·workspace output이 없는 기본 화면만 캡처해 layout/empty state를 점검한다.

## 제외 범위

- 실제 Provider 로그인·OAuth·채팅·terminal command 실행
- reboot, Doze, battery restriction, runtime reset 또는 data deletion
- tablet product install, signed release AAB, Play 배포

## 공통 진행 규칙

- token, client ID, prompt, workspace path, raw terminal output 또는 device serial을 capture/report에 남기지 않는다.
- 테스트 앱이 설치되면 즉시 제거하고 Samsung 최종 상태는 integrated product만 유지한다.
- package install과 cold start는 user data를 clear/reset하지 않는다.
- 화면 visual 점검은 자동화된 accessibility/functional 회귀를 대체하지 않는다.
