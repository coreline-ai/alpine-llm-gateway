이 문서는 Provider 정책 재검토 범위를 고정하고, 실제 계정 없이도 추정으로 자동 재시도나
모델 지원을 승격하지 않도록 하기 위한 작업 문서다.

## 개발 목적

OpenAI·Anthropic·Gemini·xAI의 최신 **공식 문서**를 기준으로 모델·오류·idempotency 경계를
재확인하고, 현재 두 채팅 모드가 계속 fail-closed 정책을 지키는지 회귀 검증한다.

## 개발 범위

- 공식 모델/오류/rate-limit/idempotency 문서 링크와 재검토 결론을 기록한다.
- `NONE` capability에서 자동 replay가 금지됨을 코드 주석과 router regression으로 고정한다.
- 실제 계정 E2E runbook의 로컬 fault 기준선 수치를 최신화한다.

## 제외 범위

- 실제 OAuth/API/model 호출, token·API key·client ID 입력 또는 다른 앱/CLI 등록값 사용
- Provider가 명시하지 않은 idempotency header 구현 및 automatic retry
- model discovery UI, Provider catalog 추가, 배포 승인 상태 변경

- raw credential, prompt, Provider error body를 문서·테스트 출력에 넣지 않는다.
- 앱의 retry UI 가능 여부와 transport automatic replay를 혼동하지 않는다.
