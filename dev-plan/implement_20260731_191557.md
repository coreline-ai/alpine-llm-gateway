이 문서는 Python Gateway의 정책·오류·리소스 경계를 최초 목적에 맞게 보강하고, 구현이 Android OAuth나 Provider 확장 범위로 번지지 않도록 하기 위한 작업 문서다.

## 개발 목적

Alpine Linux 샌드박스에서 동작하는 표준 라이브러리 기반 Gateway가 제한된 메모리 안에서 예측 가능한 OpenAI 호환 요청·스트림 계약을 제공하도록 한다. 입력 타입과 모델 정책을 명확히 하고, Provider 원문 오류·예외 문자열을 외부 응답에 노출하지 않으며, Python/Android 릴리스 버전을 일치시킨다.

## 개발 범위

- Streaming 요청의 정책 검증을 HTTP 200 전 수행한다.
- 스트림 시작 후 오류를 닫힌 SSE error schema로 정규화하고 정상 종료 표식을 보낸다.
- 일반 completion과 streaming에서 Provider 원문 오류·내부 예외를 응답에 노출하지 않는다.
- Provider JSON, Provider 오류 body, SSE 단일 event와 전체 stream 크기를 제한한다.
- `stream` 입력은 JSON Boolean만 허용한다.
- `allowed_models`와 `allow_passthrough`를 실제 Policy Engine에 연결한다.
- Python package 버전을 프로젝트 버전 `0.3.0`과 일치시킨다.
- 위 경계에 대한 Python 회귀 테스트와 README/config 설명을 추가한다.
