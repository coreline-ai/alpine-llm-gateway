# implement_20260807_221755.md

작성 일시: `2026-08-07 22:17:55 KST`

이 문서는 Provider 제품 UI의 남은 P1인 긴 텍스트 overflow, compact·landscape 적응, TalkBack 의미와 touch target을 보강하는 작업 범위를 고정한다.

## 개발 목적

- 긴 Provider 이름과 model이 card 구조나 action을 밀어내지 않게 명시적 줄 수·ellipsis 정책을 적용한다.
- 시각적으로 생략된 문자열도 Compose semantics에는 원문을 유지해 TalkBack이 전체 값을 읽을 수 있게 한다.
- 반복되는 로그인·설정·작업 메뉴 action을 Provider 이름과 결합한 접근성 label로 구분한다.
- 360×800 compact viewport, landscape와 200% font에서도 Provider 선택·연결·설정 action이 스크롤로 접근 가능하게 한다.
- 주요 action의 최소 48dp touch target과 상태 안내 semantics를 자동 테스트로 고정한다.

## 개발 범위

- Provider profile card 제목·model·상태·action overflow 및 semantics
- Provider chooser의 고정 높이를 available-height 기반 adaptive sheet로 변경

- Samsung `SM_S931N` 실기기 회귀

## 구현 결과

- Provider 이름은 최대 2줄, model은 최대 3줄 ellipsis를 사용하며 Compose semantics에는 원문을 유지한다.
- card에 연결 상태·model 또는 고정 오류 안내의 `stateDescription`을 제공한다.
- 로그인·로그아웃·재로그인·설정·작업 메뉴·진행률·취소 label에 Provider 이름을 결합했다.
- Provider card action과 chooser 취소 action에 명시적 최소 48dp touch target을 적용했다.
- Provider chooser를 고정 `680.dp`에서 available height의 `92%`를 사용하는 adaptive sheet로 변경했다.
- Samsung `SM_S931N`에서 Provider Compose 9개와 기존 Provider edit lifecycle 1개가 통과했다.
- Provider unit, Provider/demo/integrated Lint, demo/integrated build와 `git diff --check`가 통과했다.
- 최종 통합 APK를 Samsung에 설치하고 `dev.alpine.integrated/.IntegratedMainActivity` 실행을 확인했다.

## 잔여 리스크 / 후속 과제

- 실제 TalkBack 서비스 음성과 focus traversal은 수동 접근성 QA가 필요하다.
- foldable·tablet·x86_64 emulator screenshot/device matrix는 별도 환경 검증이 필요하다.
- first-run 모드 안내는 `implement_20260807_223201.md`에서 구현하고 Samsung 통합 회귀 9/9를 통과했다.
- 다음 구현 대상은 실제 TalkBack 수동 접근성 QA 또는 OAuth callback을 포함한 destructive lifecycle이며, 후자는 승인된 실계정 환경에서 검증한다.
