# implement_20260810_135747.md

작성 일시: `2026-08-10 13:57:47 KST`

이 문서는 빠른 채팅 화면을 대화 중심으로 재배치하는 이번 개발의 범위를 고정한다.

## 개발 목적

- 상단의 Provider·모델·응답 설정을 기본적으로 한 줄 context bar로 축소해 대화 목록의 높이를 늘린다.
- 사용자가 context bar를 명시적으로 펼쳤을 때만 기존 Provider dropdown, 모델 선택, 응답 설정을
  노출한다.
- 중첩 Scaffold의 navigation inset 중복을 제거해 메시지 입력창을 system navigation 바로 위에
  고정한다.

## 개발 범위

- `AlpineChatScreen`의 context controls 접힘/펼침 state와 compact summary UI
- 기존 `ProviderSelector`, `ModelQuickSwitcher`, `AssistantModeControl`의 동작·test tag·접근성
  semantics를 보존한 expanded section 조립
- `ChatComposer`의 redundant navigation bar padding 제거 및 IME/streaming 입력 동작 회귀 확인
- Compose/instrumentation test tag 보강, debug APK 빌드와 Samsung `R3CY40PXCAP` 확인

## 제외 범위

- Provider OAuth, 모델 목록·선택 상태, 대화 저장·routing·streaming protocol 변경
- 상단 제품 header 또는 빠른 채팅/Alpine 작업 실행 mode의 기능 변경
- 새 navigation bar, 디자인 시스템 교체, 애니메이션 라이브러리 또는 의존성 추가
- 실제 Provider 호출, OAuth 재로그인, 앱 데이터 삭제·uninstall
