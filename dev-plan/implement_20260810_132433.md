작성 일시: `2026-08-10 13:24:33 KST`

## 개발 목적

- OpenMinis의 xAI OAuth 흐름을 **참조**하여, Alpine debug APK에서만 Grok OAuth 로그인과
  Chat Completions 기반 1턴 스트리밍을 검증한다.
- 이미 있는 Alpine OAuth 보안 경계(PKCE, state 검증, `127.0.0.1` loopback, encrypted token
  store, redacted failure)를 재사용하고, 참조 구현의 비안전한 동작은 이식하지 않는다.
- xAI OAuth consumer 호환은 공식 Android public-client/inference grant의 증명이 아니므로
  release에는 절대 포함하지 않고 `experimental debug compatibility`로만 유지한다.

## 개발 범위

- `XaiOAuthCompatibilityConfig` 및 process-local registry를 Android library에 추가한다.
- `integrated-app/src/debug`에서만 사용자 승인 OpenMinis xAI consumer registration, 추가 scope,
  authorization metadata, Chat Completions endpoint와 모델 후보를 설치한다.
- xAI profile draft, validation, provider session factory가 호환 registry가 있는 경우에만 고정
  OAuth contract와 debug 모델 후보를 사용하게 한다.
- authorization-code token 교환에만 참조 구현이 요구하는 PKCE challenge echo를 추가하고,
  refresh token 교환은 표준 parameter만 사용한다.
- release verifier가 OpenMinis xAI registration·scope·authorization metadata가 main/release
  source와 artifact에 존재하면 실패하고, 승인된 debug source/APK에서만 정확한 fingerprint를
  허용하게 한다.
- 단위 테스트, debug assemble/install, Samsung `R3CY40PXCAP`에서 OAuth 로그인과 단일 stream
  chat turn을 실행한다.

## 제외 범위

- release/releaseCandidate APK, store signing key, API key, provider-owned OAuth registration,
  background retry, automatic replay/fallback, 동적 models API 호출
- raw OAuth redirect/token/request/response/prompt/account 식별자 기록 또는 추출
- OpenMinis GPL-3.0 소스의 복사·변형·결합
- xAI Responses API 전환, Stop/refresh/logout/429·5xx의 실제 계정 유발 검증

## 사전 검토 결과와 결정

- [x] 현재 `XaiOAuthContract`는 xAI discovery, exact `auth.x.ai` host, HTTPS endpoint,
  `127.0.0.1:56121/callback`, standard PKCE, encrypted token store를 이미 제공한다.
- [x] OpenMinis는 consumer/CLI registration·추가 scope·authorization metadata와
  authorization-code PKCE challenge echo를 사용한다. 해당 값은 debug app source set에만 둔다.
- [x] OpenMinis callback 구현의 raw URI/request logging, wildcard socket bind, substring CORS
  검사, nonce/ID-token 검증 공백, token/API-key store 혼용은 채택하지 않는다.
- [x] xAI의 공개 REST 문서는 API-key 인증을 설명한다. 이 consumer OAuth inference 경로는
  provider의 공식 Android OAuth 승인이 아니므로 제품 배포 근거가 될 수 없다.
- [x] Chat Completions은 Alpine의 기존 SSE adapter와 맞아 이번 최소 검증에 사용한다. model
  후보는 UI 선택 편의일 뿐 entitlement 보장이 아니며, dispatch는 사용자가 고른 한 모델로만 한다.

## 공통 진행 규칙

- 모든 호환 값은 process-local registry와 `integrated-app/src/debug`에만 둔다. main source,
  release manifest, 문서 예시, release artifact에는 포함하지 않는다.
- OAuth token, code, PKCE state/verifier, callback query, authorization header, raw provider
  response, prompt, account 정보는 console/logcat/계획/테스트 fixture에 남기지 않는다.
- 모든 provider 오류와 SSE 중단은 사용자의 명시적 Retry 전까지 자동 재전송하지 않는다.
- 실제 기기는 Samsung serial `R3CY40PXCAP`만 사용하며, 앱 데이터 삭제·uninstall 없이 debug APK를
  `install -r` 한다. 계정 비밀번호·MFA는 사용자만 입력한다.
- 각 Phase의 체크박스와 결과를 실제 상태로 갱신한다. 테스트 실패는 우회하지 않고 원인을 수정한다.

## 잔여 리스크 / 후속 과제

- provider가 Alpine 소유 Android OAuth client와 inference scope를 공식 승인하기 전에는 이 경로를
  release로 승격하지 않는다.
- xAI 공식 model discovery/Responses migration은 별도 설계·계정 entitlement E2E와 함께 검토한다.

  기록한다.
