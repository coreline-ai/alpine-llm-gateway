작성 일시: `2026-08-04 22:54:17 KST`

이 문서는 MobileAgent의 남은 핵심 작업 중 현재 로컬 환경에서 구현·검증 가능한 **대화 영속화·복구·검색·삭제** 범위를 고정하기 위한 작업 문서다.

## 개발 목적

- 사용자가 Android/iOS Flutter 앱에서 최근 대화를 안전하게 복구·검색·삭제하게 한다.
- 대화 본문을 Dart 평문 파일이나 SharedPreferences에 저장하지 않고 플랫폼 native encrypted vault에만 보관한다.
- 대화 삭제의 범위를 "이 기기의 로컬 암호화 사본"으로 정확히 표시해 IdP/BFF/Provider 데이터 삭제와 혼동하지 않게 한다.

## 개발 범위

- `mobile_agent_auth` native plugin에 conversation vault method channel 추가
- Android Keystore AES/GCM + no-backup app-private 파일
- iOS Keychain key + CryptoKit AES.GCM + app-private file protection
- Flutter `ConversationStore` 모델, 입력/크기 제한, native payload 검증
- `ChatController` 대화 생성·복구·검색·선택·삭제·전체 삭제 연결
- Flutter GUI의 recent conversation, search, delete와 local-only 고지
- Dart contract/widget, Android build, iOS Simulator build, release scanner 검증

## 제외 범위

- BFF/Provider/IdP 서버의 account deletion 또는 upstream prompt 삭제
- 클라우드 동기화, 다기기 merge, export/import, 백업 복원
- Pigeon migration, Redis, Provider 실계정 E2E
- 운영 개인정보 고지·retention policy의 법률 승인
- 저장된 대화에 tool result, attachment, raw Provider error body를 포함하는 기능

## 공통 진행 규칙

- 대화 vault에는 access/refresh/id token, Authorization header, Provider API key, raw upstream body를 저장하지 않는다.
- native file은 app-private/no-backup 경로만 사용하고 암호화 전 평문을 파일에 쓰지 않는다.
- 모든 대화 데이터는 bounded schema와 최대 크기를 확인한 뒤 저장한다.
- native 저장소 오류는 원문 exception 없이 안정된 `conversation_storage_failure`로 Dart에 전달한다.
- local delete 성공은 server/Provider delete 성공으로 표시하지 않는다.
- Android/iOS method key와 schema version은 같은 계약으로 유지한다.

## 잔여 리스크 / 후속 과제

- native encrypted vault은 이 기기 로컬 사본만 다룬다. Provider/BFF/IdP retention·계정 삭제는 별도 운영 계약이 필요하다.
- device lock, Keystore/Keychain invalidation, low-storage와 reinstall data retention은 실제 Android/iPhone에서 별도 검증해야 한다.
- Pigeon typed channel은 vault schema가 안정된 뒤 auth/transport/conversation method channel을 함께 migration한다.
