# implement_20260808_141500.md

작성 일시: `2026-08-08 14:15 KST`

## 목적

PRoot guest 동적 terminal resize의 남은 원인을 실제 Samsung arm64에서 추가로 분리한다.
기존 `INITIAL_SIZE_ONLY` 제품 계약을 약화시키지 않고, controlling terminal 소유권만을
명시하는 native launcher 대안이 guest `stty`와 `SIGWINCH`까지 전달되는지 검증한다.

## 범위와 안전 조건

- 대상: `:alpine-runtime-android`, 개발용 `:alpine-runtime-probe`, Samsung `R3CY40PXCAP`.
- Probe 전용으로 `setsid()` → `TIOCSCTTY` → `tcsetpgrp()` → PRoot `exec` launcher와
  Host-private winsize state/기존 PRoot `TIOCGWINSZ` hook을 시험한다.
- 실제 guest `stty size`, foreground `SIGWINCH`, 반복 resize가 모두 통과하기 전에는 제품의
  `DYNAMIC` capability를 켜지 않는다.
- 실패한 실험 코드·artifact는 제품 APK에 남기지 않는다. FIFO, polling, `/proc/<pid>/fd` 재개방을
  복구하지 않는다.

## 수행 결과

- [x] native launcher가 arm64/x86_64 debug APK에 packaging되는지 확인했다.
- [x] Probe에서 `96×28 → 120×40 → 80×24` resize와 BusyBox `stty size`, `trap WINCH`를
  명시적으로 검증하도록 만들었다.
- [x] Samsung에서 launcher + Host-private state + `PROOT_NO_SECCOMP=1`을 실행했다.
- [x] 결과: Host call은 실패하지 않았지만 guest `stty size`는 세 단계 모두 `28 96`이었다.
  interactive shell의 `WINCH` trap도 호출되지 않았다.
- [x] 결론: controlling-terminal launcher만으로는 PRoot tracee의 실제 foreground terminal과
  signal/winsize 경로를 보장하지 못한다. 이 구현은 source-level 해결로 승격하지 않는다.
- [x] 임시 native launcher/state/probe experiment를 제거하고, bundled product APK에서 해당 helper가
  없음을 확인했다.
- [x] 기존 fail-closed Probe를 다시 실행해 `INITIAL_SIZE_ONLY`,
  `TERMINAL_RESIZE_UNSUPPORTED`, initial `stty size=28 96`, terminal close event,
  `STARTED:3/STOPPED:3`, `READY`/healthy를 확인했다.
- [x] Probe를 uninstall하고 `dev.alpine.integrated/.IntegratedMainActivity`를 재설치·cold start했다.
- [x] normal native-PTY topology Probe에서 Guest tty attached=true, process-group=foreground=true,
  process-group=session-leader=false를 확인했다. 따라서 단순 session ownership 가설은 해소됐고,
  next source-level proof는 master/Guest tty identity와 actual foreground `SIGWINCH`, PRoot ioctl result다.

## 다음 source-level 조건

1. pinned PRoot source와 Host PTY에서 master/Guest tty 동일성, tracer/tracee/foreground pgrp의
   resize·signal 경로를 syscall 수준으로 증명한다.
2. PRoot가 actual foreground process group에 `SIGWINCH`를 전달하고 guest `TIOCGWINSZ`가 진짜
   size를 읽도록 수정한 별도 binary를 재현 가능하게 빌드한다.
3. 동일 Samsung ABI에서 `stty size`, `SIGWINCH`, `40×120/80×24` 반복·storm·rotation,
   vi/nano/top 및 종료 뒤 orphan 없음까지 통과한 경우에만 public capability를 `DYNAMIC`으로 변경한다.

그 전까지 release readiness의 `GUEST_WINSIZE_NOT_PROPAGATED`는 `BLOCKED`를 유지한다.
