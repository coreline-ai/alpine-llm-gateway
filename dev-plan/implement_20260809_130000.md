# PRoot pinned source provenance 재검증 계획

작성 일시: `2026-08-09 13:00:00 KST`

## 목적

이전 전체 로컬 회귀에서는 Git metadata가 없는 OSS source bundle로 PRoot static handoff invariant만
검사했다. 현재 machine에 runtime lock의 OpenMinis commit과 정확히 일치하는 read-only checkout이 있음을
확인했으므로, source revision·stock handoff·packaged arm64 binary 검증의 증거를 분리해 다시 수집한다.

이 작업은 동적 resize를 성공으로 표시하거나 product terminal 동작을 바꾸지 않는다. PRoot guest의
`SIGWINCH`·repeat/storm/rotation/TUI acceptance는 이 source audit만으로 증명할 수 없으므로 public contract는
계속 `INITIAL_SIZE_ONLY`/`TERMINAL_RESIZE_UNSUPPORTED`다.

## 범위

- runtime lock의 PRoot revision과 local OpenMinis checkout HEAD를 대조한다.
- pinned checkout을 `verify-proot-terminal-handoff.py`의 revision-check 대상에 사용한다.
- packaged arm64 Runtime의 checksum·ELF ABI·16 KiB alignment를 toolchain lock 및 Gradle artifact verifier로
  재확인한다.
- 감사·검증 문서의 bundle-only `--skip-revision-check` 표현을 정확한 pinned-source evidence로 보완한다.

## 제외 범위

- PRoot source patch, PID/fd reopen, guest signal injection, host→guest relay, polling/FIFO/memfd/replay 우회
- Samsung reboot/Doze/battery/8시간 soak, real Provider, Play/원격 CI, x86_64 emulator
- rootfs corresponding-source mirror 또는 프로젝트 라이선스의 외부 결정

## 안전 조건

- canonical source checkout은 읽기 전용으로 다루며 source/binary를 수정하거나 재패키징하지 않는다.
- report에는 source code/commit hash·terminal raw output·PID·credential을 기록하지 않는다.
- provenance check가 통과해도 dynamic resize capability를 올리지 않는다.

- [x] packaged arm64 binary checksum/ELF alignment가 검증된다.
- [x] 문서가 source provenance와 dynamic resize `NOT_PROVEN` 상태를 혼동하지 않는다.

## 실행 결과

- lock의 PRoot revision과 local OpenMinis read-only checkout HEAD가 일치했다.
- `verify-proot-terminal-handoff.py --proot-source <pinned checkout>`은 revision match와 stock
  Android ioctl/signal handoff invariant를 통과했다. 결과는 `dynamic_resize_status=NOT_PROVEN`이다.
- arm64 unpatched toolchain verifier는 packaged launcher/loader의 checksum, ABI 및 모든 load segment의
  16 KiB alignment를 통과했고, `:alpine-runtime-pack-bundled:verifyBundledRuntimeArtifacts`도 성공했다.
- 이 검증은 source provenance와 packaged binary boundary만 강화한다. physical guest resize, foreground
  `SIGWINCH`, input continuity, repeat/storm, rotation, TUI, orphan cleanup은 검증하지 않았으므로 terminal
  public contract와 readiness blocker는 변경하지 않았다.
