## 개발 목적

현재 Android OAuth/Host Bridge와 Alpine runtime 기반 위에 CI를 제외한 즉시 구현 가능 항목을 추가한다. 외부 Provider credential이나 실제 rootfs 바이너리 없이도 스트리밍, 장애 복원력, 관측성, 샘플 통합, ABI·무결성 경계와 릴리스 산출 절차를 자동 검증 가능한 상태로 만드는 것이 목적이다.

## 개발 범위

- Android OAuth Provider 응답을 Host Bridge와 Alpine CLI까지 전달하는 SSE 스트리밍 계약을 구현한다.
- 스트리밍 연결 취소, 요청 timeout, event/response 크기 제한을 구현한다.
- 재시도·지수 백오프·`Retry-After`·circuit breaker를 HTTP transport 장식자로 구현한다.
- credential, URL, request/response body를 기록하지 않는 구조화 운영 event sink를 추가한다.
- Claude, Gemini, OpenAI-compatible 스트림 event를 공통 `start/delta/done` 형식으로 정규화한다.
- text 응답 계약을 유지하면서 tool call과 inline image message 변환을 Provider adapter에 추가한다.
- Android 샘플 앱과 emulator/device에서 실행 가능한 instrumentation test를 추가한다.
- Alpine runtime의 ABI별 PRoot asset 선택, SHA-256 검증, 설치 상태 조회 경계를 추가한다.
- CI 없이 로컬에서 release AAR, sources JAR, checksum을 생성하는 릴리스 스크립트를 추가한다.
- 문서와 전체 회귀 테스트를 갱신한다.

## 제외 범위
