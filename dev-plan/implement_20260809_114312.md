# implement_20260809_114312.md

작성 일시: `2026-08-09 11:43:12 KST`

이 문서는 Alpine AI Workspace의 남은 비파괴적 기기 회귀 범위 중 연결된 Android 태블릿에서
통합 앱 화면·Compose lifecycle·빠른 채팅 fallback 회귀를 현재 artifact로 검증하고, 실패하면
테스트/제품 경계를 유지한 채 수정하기 위한 작업 문서다.

## 개발 목적

- Samsung 전용 PASS를 tablet/foldable 레이아웃 지원 완료 주장으로 과장하지 않는다.
- 실제 연결된 Android 12 태블릿에서 `integrated-app` fake-Provider instrumentation을 재실행한다.
- 화면 보호기와 이전 Activity teardown이 Compose root를 가리는 환경 회귀를 제품 코드나 보안 정책을
  바꾸지 않고 test-only fixture에서 fail-fast로 다룬다.

## 개발 범위

- `IntegratedFastChatInstrumentedTest`의 Activity lifecycle test fixture와 화면 접근 전제를 검토한다.
- 연결된 태블릿에서 통합 app 10개 instrumentation을 실행한다.
- 최종 제품 APK만 남기고 cold start를 확인한다.
- 실제 결과를 GOAL audit·검증 문서에 기록한다.

## 제외 범위

- Samsung reboot/Doze/process-kill, battery restriction, 장시간 soak
- 외부 Provider 계정, OAuth browser callback, prompt/credential을 쓰는 테스트
- PRoot guest dynamic resize와 x86_64 Emulator E2E
- 제품 UI에 wake/unlock 동작을 추가하거나 Keyguard를 우회하는 변경
