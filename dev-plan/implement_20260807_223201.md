# implement_20260807_223201.md

작성 일시: `2026-08-07 22:32:01 KST`

이 문서는 통합 앱의 다음 P1인 **빠른 채팅과 Alpine 작업 모드 first-run 안내**를 구현하기 위한 범위를 고정한다.

## 개발 목적

- 첫 실행에서 두 모드의 실행 경로, 준비 조건, 지원 기능과 제한을 사용자가 선택 전에 이해하게 한다.
- 빠른 채팅은 Android 직접 Provider 연결이고 Alpine 작업은 Runtime·HostBridge·Python Gateway를 사용하는 경로임을 명확히 구분한다.
- Alpine 준비 실패 시 자동으로 직접 Provider에 재전송하지 않고 사용자 승인 fallback만 허용한다는 정책을 안내한다.
- 사용자가 안내에서 시작 모드를 선택하고, 이후 언제든 모드 selector에서 안내를 다시 열 수 있게 한다.
- 안내 완료 여부를 versioned local preference로 저장하되 계정·token·대화 데이터는 저장하지 않는다.

## 개발 범위

- 통합 앱 전용 first-run guide state store
- adaptive·scrollable mode guide bottom sheet
- 빠른 채팅/Alpine 작업의 준비·기능·제한·복구 설명
- first-run 자동 표시, 명시적 시작 선택, 임시 닫기, 재열기
- 완료 상태 persistence와 Activity restart 회귀
- 200% font·compact viewport action 접근성
- Samsung `SM_S931N` 실기기 회귀와 상위 계획 동기화

## 제외 범위

- Provider 실제 OAuth 로그인 자동 수행
- Alpine Runtime 자동 설치·자동 시작

## 구현 결과

- `IntegratedModeGuideStore`는 `completed_version` 정수 한 개만 저장하며 구 guide version은 자동 미완료로 판정한다.
- 첫 실행 guide는 두 모드의 실행 경로·준비·지원 기능·제한·복구와 승인 기반 fallback 정책을 표시한다.
- `나중에`는 현재 실행에서만 닫고, 두 시작 action은 mode 선택과 완료 저장을 함께 수행한다.
- 완료 후에도 상단 `안내` action으로 재열 수 있으며 Alpine 선택만으로 Runtime 또는 Provider 요청을 시작하지 않는다.
- Samsung `SM_S931N`에서 기존 채팅·fallback 4건과 신규 first-run·persistence·200% font 5건, 총 9/9가 통과했다.
- integrated Lint, debug APK, AndroidTest APK build와 삼성폰 최종 설치·실행·portrait 시각 검증을 완료했다.

## 잔여 리스크 / 다음 후속
