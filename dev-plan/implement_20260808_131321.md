## 목적

terminal session UI에서 interrupt와 별도로 정상 종료(SIGTERM)와 강제 종료(SIGKILL)를 명시적으로 제공한다. 단, destructive signal은 확인 dialog 뒤에만 dispatch하고, raw command/output/PID를 UI나 event state에 기록하지 않는다.

## 범위

- `:alpine-runtime-ui-compose`가 현재 선택한 open terminal에만 `TERMINATE`/`KILL` action을 전달한다.
- `:integrated-app`은 기존 reusable `RuntimeHostController.signalTerminal()`을 통해 signal을 전달한다.
- `KILL`은 별도 확인 dialog를 거쳐야 하며 cancel은 signal을 dispatch하지 않는다.

## 제외 범위

- PRoot dynamic resize, full TUI compatibility, background/reboot/Doze 수동 검증
- 다른 terminal tab·runtime 전체·Gateway의 무단 종료, command 자동 재실행
