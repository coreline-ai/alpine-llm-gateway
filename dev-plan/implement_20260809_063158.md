# Phase 1f: PRoot second `TIOCGWINSZ` lifecycle 분리

작성 일시: `2026-08-09 06:31:58 KST`

## 목적

Relay28은 첫 successful guest `TIOCGWINSZ` 뒤 단순 고정 `printf`가 Samsung에서 응답함을 증명했다. 그러나
두 번째 `TIOCGWINSZ`를 **요청하는** fixed marker의 completion은 증명하지 못했다. 이 단계는 source-level
Probe-only recorder로 두 번째 get-size 요청의 enter/exit 도달 여부만 고정 enum으로 분리한다.

## 안전 경계

- `Relay29`는 `:alpine-runtime-probe`에만 존재하는 disposable PRoot artifact다.
- recorder는 순서와 성공/실패 class만 기록한다. terminal bytes, command, argument, path, PID, fd number,
  errno raw value, credential은 기록하지 않는다.
- 이 작업은 command replay/retry, polling/FIFO, PID/fd re-open, post-launch signal injection을 만들지 않는다.
- dynamic resize capability나 product artifact를 변경하지 않으며, product는 `INITIAL_SIZE_ONLY`를 유지한다.

## 구현 체크리스트

- [x] 첫 successful `TIOCGWINSZ` 뒤 두 번째 요청의 enter/exit class recorder를 추가했다.
- [x] Probe pack, artifact lock, Gradle checksum, parser JSON, intent flag, module-boundary 회귀를 연결했다.
- [x] arm64 source patch build와 Probe unit/boundary build를 실행했다.
- [x] Samsung seccomp-off fixed-marker run으로 stage 결과를 확인했다.
- [x] Probe 제거 뒤 `dev.alpine.integrated`만 남기고 cold start했다.
- [x] 결과·한계·release readiness를 문서에 동기화했다.

## Samsung arm64 결과

Relay29 seccomp-off marker run은 첫 get success `1`, 두 번째 get enter `1`, 두 번째 get success `1`, 두 번째
get error `0`을 보였다. 그러나 marker response 및 dynamic-resize contract는 모두 false였다. 따라서 두 번째
`TIOCGWINSZ` 자체가 enter 전에 사라지거나 ioctl error로 끝난다는 가설은 제거한다. 남은 조사 범위는 성공한
두 번째 get **이후**의 child completion, parent wait/read/write, 또는 PTY delivery 경계다. 이 fixed enum 증거는
raw errno, terminal data, command 또는 identifier를 포함하지 않는다.

## 판정

- [x] 두 번째 `TIOCGWINSZ` enter와 success exit을 확인했다.
- [x] marker completion 실패를 두 번째 ioctl 자체의 실패로 단정하지 않는다.
- [x] product는 `INITIAL_SIZE_ONLY`/`TERMINAL_RESIZE_UNSUPPORTED`를 유지한다.
- [x] Samsung에는 최종 `dev.alpine.integrated`만 남겼다.

## 승격 조건

Relay29는 원인 조사 증거일 뿐이다. 다음 후보는 두 번째 successful get 이후 child exit와 parent wait/read/write를
payload 없이 분리하는 maintained-source trace다. maintained source-level fix 또는 alternative terminal backend가
repeat/storm/rotation/`SIGWINCH`/TUI/orphan acceptance matrix를 통과하기 전에는 `DYNAMIC`을 광고하지 않는다.
