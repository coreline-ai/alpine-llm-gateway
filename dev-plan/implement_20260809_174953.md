이 문서는 Alpine LLM Gateway와 MobileAgent Flutter 제품을 소스·검증·문서·Git 이력 기준으로 분리하기 위한 작업 문서다.

## 개발 목적

- `coreline-ai/alpine-llm-gateway`를 Alpine Linux Gateway·Android Runtime SDK·통합 Android 앱만 포함하는 저장소로 복원한다.
- `coreline-ai/flutter_mobile_agent`를 Android/iOS Flutter 앱, Flutter 플러그인, MobileAgent BFF와 개발 OIDC fixture를 포함하는 독립 저장소로 재구성한다.
- 기존의 공유 가능 Android OAuth Provider 코드는 Alpine 제품에 남기고, MobileAgent 전용 코드만 이동한다.

## 개발 범위

- Flutter 저장소에 `apps/mobile_agent`, `packages/mobile_agent_auth`, `packages/mobile_agent_llm_transport`, `backend/mobile_agent_bff`, `backend/dev-idp`와 MobileAgent 전용 검증·문서·화면 자산을 이관한다.
- Flutter 저장소의 루트 README, Makefile, GitHub Actions CI, OAuth release scanner와 Python 계약 테스트를 독립 경로로 정리한다.
- Alpine 저장소에서 MobileAgent 전용 경로·Makefile·스크린샷·문서 링크·테스트를 제거한다.
- Alpine 전용 OAuth release scanner는 명확한 이름으로 유지하고 CI 참조를 갱신한다.
- 현재 사용 중인 Alpine 작업 트리의 미커밋 변경은 수정하거나 커밋하지 않는다. 깨끗한 임시 복제본에서 분리 커밋을 만든다.

## 제외 범위

- Alpine Android Provider/OAuth 구현을 Flutter 저장소로 이동하거나 API를 재설계하지 않는다.
- 실제 Provider 계정 OAuth E2E, Play Console/TestFlight 설정, signing, DNS/HTTPS issuer/BFF 배포는 수행하지 않는다.
- 이미 잘못 섞인 Git 이력은 Flutter 저장소에서 독립 orphan root commit으로 교체한다. 이력 보존용 별도 mirror/tag 작성은 하지 않는다.
- MobileAgent 기능·GUI·Provider 계약의 신규 기능 추가는 하지 않는다.
