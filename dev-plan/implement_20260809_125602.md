# x86_64 Emulator Gate 개인정보 최소화·환경 감사 계획

작성 일시: `2026-08-09 12:56:02 KST`

## 목적

x86_64 emulator E2E가 아직 없더라도 gate report와 내부 SDK release bundle에 ADB device serial이
저장되지 않게 하고, 현재 SDK/AVD/image 환경에서 실제 E2E 실행 가능 여부를 fail-closed로 재확인한다.

## 범위 및 안전 조건

- `scripts/runtime/run-x86_64-emulator-gate.sh`의 report schema와 해당 regression만 변경한다.
- ADB serial은 runtime selector로만 사용하고 JSON·stdout report·SDK bundle 입력에는 저장하지 않는다.
- 기존 AVD를 생성·삭제·wipe하지 않고, system image 다운로드나 host SDK 갱신은 하지 않는다.
- x86_64 image가 없으면 ARM64 결과로 대체하지 않고 gate를 계속 `BLOCKED`로 유지한다.

## 구현 단계

- [x] Phase 1. 로컬 SDK와 AVD를 감사해 ARM64 API 26·35 image/AVD만 존재하고 x86_64 image가 없음을 확인한다.
- [x] Phase 2. x86 gate report schema에서 serial을 제거하고 `device_class=android_emulator`와 stable
  reason/provenance만 보존한다.
- [x] Phase 3. fake ADB regression으로 report가 input serial을 보관하지 않는지 검증하고 bash syntax를 확인한다.
- [x] Phase 4. 연결 기기에서 `--allow-skip` gate를 실행해 `SKIP_NO_X86_64_EMULATOR`와 serial 미포함
  report를 확인한다.
- [x] Phase 5. 검증 문서·GOAL audit에 x86 E2E 미실행과 다음 실행 조건을 동기화한다.

## 결과

- gate report schema는 `3`이며 `serial` field가 없다. ADB에는 내부적으로만 serial을 전달하고 report에는
  ABI, stable status/reason, generic device class, model/API(연결된 x86 emulator가 있을 때), artifact provenance만 남긴다.
- `tests/test_x86_64_emulator_gate.py`가 fake ADB serial이 generated JSON에 없음을 검증한다.
- 현재 host에는 ARM64 API 26·35 image/AVD만 있어 x86 gate는 `SKIP_NO_X86_64_EMULATOR`로 끝났다.

## 다음 실행 조건

1. 승인된 x86_64 Android system image를 설치하고 새 disposable AVD를 만든다.
2. headless/no-snapshot-save로 boot한 뒤 `scripts/runtime/run-x86_64-emulator-gate.sh`를 skip 없이 실행한다.
3. runtime probe의 install/start/health/exec/terminal/restart 및 `x86_64` ABI를 모두 확인할 때만 gate를 해제한다.

이 변경은 x86_64 runtime E2E, PRoot dynamic resize, 실제 Provider, Samsung destructive lifecycle 또는 공개 배포를
완료로 만들지 않는다.
