## Production-level 제품 판정 (배포 제외)

### 코드 기준 완료

- fast chat, common chat feature, encrypted history, persona/skill, Stop/retry와 direct/Alpine routing
- Runtime install/start/repair, Gateway health/recovery/no-replay, terminal/session, workspace/SAF/share,
  package allowlist/approval/simulation 및 developer tool profiles
- credential isolation, redacted error/size bounds, no post-dispatch fallback/replay, Provider idempotency fail-closed
- Samsung/tablet/ARM64 automated regression, local security/supply-chain scanners

### production 기능 제약 (미구현으로 취급하지 않음)

- guest dynamic terminal resize는 지원하지 않으며 terminal 시작 크기만 적용한다.
- package metadata는 approved snapshot 기준이며 live repository 운영 판단은 별도 운영 검증이다.
- Codex/OpenAI Responses direct OAuth는 앱 소유 registration과 승인 endpoint가 없으면 연결 화면에서 설정 상태로 남는다.

### 제품 완료를 막는 외부 검증

1. 현재 최종 통합 앱의 Codex/OpenAI profile 등록 및 실제 one-request E2E
2. Samsung reboot/Doze/process-kill 및 OEM background lifecycle 승인 검증
3. Intel/AMD x86_64 host 또는 연결된 x86_64 emulator에서 Runtime E2E
4. DocumentsUI/physical keyboard/TalkBack 등 수동 device acceptance
