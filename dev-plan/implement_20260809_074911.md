# implement_20260809_074911.md

작성 일시: `2026-08-09 07:49:11 KST`

이 문서는 Alpine 작업 모드의 terminal 외부 키보드 control 회귀 범위를 고정한다. terminal
resize capability를 우회하거나 PRoot 동작을 변경하지 않는다.

## 개발 목적

완성형 terminal UI가 제공하는 Enter·Tab·Ctrl+C·Esc 입력이 실제 Compose 외부 키 이벤트에서도
의도한 safe host callback 하나로만 전달되는지 Samsung·tablet 계측 증거를 보강한다. standalone
panel test는 실제 `RuntimeWorkspaceScreen`과 같은 scroll container에서 touch target을 노출한다.

## 개발 범위

- 기존 `RuntimeTerminalPanel`의 키 매핑을 대상으로 instrumentation regression을 추가한다.
- Tab은 `\t`, Esc는 ESC control character, Ctrl+C는 interrupt callback으로만 전달되는지 검증한다.
- runtime UI AndroidTest를 Samsung·tablet에서 실행하고 최종 integrated product 앱만 다시 시작한다.

## 제외 범위

- PRoot guest dynamic resize, SIGWINCH, command replay/retry, TUI 실사용 검증
- 실제 SSH key·Provider credential·외부 키보드 하드웨어 연결
- terminal command나 raw output을 report에 기록하는 작업

## 공통 진행 규칙

- control key는 terminal이 active/idle일 때만 host callback으로 전달한다.
- 입력 control regression은 guest command 실행 증거가 아니며, guest resize 상태를 변경하지 않는다.
- raw terminal text, credential, device serial을 test assertion·문서에 넣지 않는다.
- 테스트 뒤 product package 외 Demo/Probe/test package를 Samsung에 남기지 않는다.
