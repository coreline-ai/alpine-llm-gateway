# implement_20260731_155401.md

작성 일시: `2026-07-31 15:54:01 KST`

이 문서는 Material 3 Compose 디자인 전환을 우선 적용하고, 기존 데모 챗봇 계획의 외부 credential 없이 구현 가능한 잔여 항목을 병렬로 완료하기 위한 작업 문서다.

## 개발 목적

`demo-chatbot`의 XML/AppCompat UI를 Material 3 Compose로 전환해 디자인 목업과 일치시키고, 오류·retry UX, profile/token lifecycle 회귀, fake multi-provider E2E와 Samsung 실기기·보안 검증까지 완료한다.

## 개발 범위

- 기존 OAuth, Provider adapter, 저장소와 `ChatCompletionSession` 계약은 유지한다.
- 세 Activity의 화면 구현을 Compose Material 3로 전환한다.
- Alpine blue 기반 light/dark theme, semantic status color와 공통 UI component를 추가한다.
- 채팅, Provider 목록, Provider 선택·설정 폼을 목업의 정보 구조로 재구성한다.
- 401/timeout/429/5xx/circuit 오류 상태와 안전한 retry를 구현한다.
- test-only session factory로 외부 credential 없는 multi-provider instrumentation을 추가한다.
- profile CRUD, token namespace, 회전, logout/delete와 연속 입력 회귀를 보강한다.
- Samsung `SM-S931N`에서 설치·instrumentation·UI smoke와 credential 비노출을 검증한다.

## 제외 범위

- 실제 Provider client registration, 계정과 과금 API E2E
- App Link/custom scheme OAuth callback
- Alpine rootfs/PRoot asset 공급과 실제 `llmctl` 실행
- Kimi/xAI, model discovery, 파일·이미지·tool UI, 영구 대화 저장
- CI, Play Store와 외부 publication
- Android library 공개 API의 불필요한 변경

## 공통 진행 규칙

- 디자인 foundation을 먼저 빌드한 뒤 병렬 leaf workstream을 통합한다.
- 각 worker는 지정된 파일만 수정하고 다른 worker의 변경을 되돌리지 않는다.
- Provider 원문 오류, endpoint, token, Authorization header와 PKCE verifier를 UI·로그에 전달하지 않는다.
- production APK에는 fake session이나 test credential 진입점을 노출하지 않는다.
- 활성 stream 중 Provider 전환, 중복 send와 profile mutation을 막는다.
- Compose semantics와 48dp touch target을 기본 완료 조건으로 둔다.
- 각 Phase는 자체 테스트를 통과한 뒤 다음 Phase로 진행한다.

## 병렬 Workstream과 파일 소유권

| ID | 작업 | 소유 경로 | 의존성 | 병렬 가능 |
|---|---|---|---|---|
| WS-F | Compose build, theme, 공통 계약 | root build, `demo-chatbot/build.gradle.kts`, `ui/theme`, `ui/state`, `DemoDependencies` | 없음 | 선행 |
| WS-UI1 | 채팅 Compose 화면 | `ui/screens/chat/**`, `MainActivity.kt` | WS-F | 가능 |
| WS-UI2 | Provider Compose 화면 | `ui/screens/provider/**`, `Provider*Activity.kt` | WS-F | 가능 |
| WS-ERR | 오류 매핑·retry·ViewModel test | `ui/ChatViewModel.kt`, `ui/ChatFailure.kt`, 관련 JVM test | WS-F | 가능 |
| WS-QA | profile/lifecycle·Compose instrumentation | `src/test/**`의 profile 영역, `src/androidTest/**` | WS-F | 가능 |
| WS-DOC | 디자인/사용 문서 | `demo-chatbot/README.md`, `demo-chatbot/DESIGN.md` | UI 계약 | 가능 |
