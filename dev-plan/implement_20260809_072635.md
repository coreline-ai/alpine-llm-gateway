# 태블릿 통합 채팅 fallback 계측 회귀 분석·수정

작성 일시: `2026-08-09 07:26:35 KST`

## 개발 목적

연결된 Android 태블릿에서 `integrated-app`의 Alpine 작업 모드 fallback 승인·거절 계측 흐름이
일관되게 완료되는지 검증한다. 승인 전에는 Direct Provider dispatch가 절대 발생하지 않고,
승인 후에는 정확히 한 번 dispatch되며, 거절 시에는 dispatch 없이 안전한 안내가 표시되어야 한다.

## 범위

- `IntegratedChatHostController`의 fallback approval handoff와 `RoutedChatBackendSession` 비동기 흐름을 점검한다.
- 태블릿에서 재현 가능한 승인·거절 instrumentation failure를 원인별로 구분한다.
- 제품 동작 결함이면 최소 수정과 회귀 테스트를 추가한다.
- Gradle UTP runner 문제와 제품/테스트 코드 결함을 분리해 기록한다.
- 검증 후 태블릿에는 최종 `dev.alpine.integrated` 제품 앱만 남기고 cold start한다.

## 제외

- Provider 실계정, OAuth credential, 실제 request/prompt/body의 기록 또는 출력
- PRoot terminal resize 정책 변경 및 signal/command replay 우회
- Samsung reboot·Doze·배터리 제한 변경·장시간 soak
- 커밋 또는 Push

## 진행 규칙

- fallback은 dispatch 이전에 사용자 승인을 받아야 하며, dispatch 이후 자동 fallback·재전송은 금지한다.
- 오류와 테스트 증거에는 token, credential, raw provider body, prompt, device 식별자를 기록하지 않는다.
- UTP가 test package 삭제 과정에서 실패하더라도 제품 로직 failure와 혼동하지 않는다.
- 테스트 package 정리와 제품 cold start 확인은 destructive device test가 아닌 범위에서 수행한다.

## 단계별 계획

### Phase A — 재현·원인 분리

- [x] 태블릿 UTP `connectedDebugAndroidTest`의 runner failure와 직접 instrumentation 경로를 분리했다.
- [x] fallback 승인과 거절 테스트가 모두 태블릿에서 재현되는지 확인했다.
- [x] 승인 후 Direct dispatch는 정확히 1회 발생하고 응답 node도 생성됨을 확인했다. 태블릿 세로
  viewport에서는 IME가 dialog로 닫힌 뒤 expanded Gateway card가 Alpine chat pane 높이를 과도하게
  축소해 응답·거절 안내가 화면에 표시되지 않는 제품 레이아웃 결함으로 판정했다.
- [x] 화면 절전 상태에서는 Android 12 Compose root가 계측에 연결되지 않는 별도 device-runner 조건도
  확인했다. 이는 앱 crash가 아니며, 검증 시작 전에 화면을 깨운 뒤 테스트했다.

### Phase B — 수정·회귀 보강

- [x] Alpine chat pane에 대화가 생긴 뒤에는 expanded Gateway card를 숨기되 pane switcher는 유지하도록
  수정했다. 상세 Gateway control은 terminal/tools pane에서 계속 제공하며, chat response·failure viewport를
  우선한다.
- [x] 승인 전 `0회`, 승인 뒤 `1회` dispatch를 명시적으로 기다리고, response가 chat list 안에 생성되어
  스크롤 뒤 표시되는지 확인하도록 instrumentation을 보강했다.
- [x] `:alpine-chat-feature:testDebugUnitTest`, `:integrated-app:lintDebug`, debug APK build와
  `IntegratedFastChatInstrumentedTest`를 실행했다.

### Phase C — 기기 검증·복구·문서

- [x] 태블릿 Android 12에서 `IntegratedFastChatInstrumentedTest` 10/10을 통과했다. 승인·거절 fallback,
  Korean IME, TalkBack semantics, compact 200% guide, history/restart 및 mode flow를 포함한다.
- [x] Samsung Android 16에서도 동일 통합 계측 10/10을 다시 통과했다.
- [x] 두 기기에서 test package를 제거하고 `dev.alpine.integrated`만 cold start했다.
- [x] 실제 결과를 계획·goal audit 문서에 반영한다. TalkBack gesture/voice와 수동 contrast QA, landscape/API26/35는
  별도 물리 matrix가 필요하므로 `NOT_RUN`으로 유지한다.

## 완료 기준

1. 승인 전 `requestCount == 0`, 승인 후 `requestCount == 1`, 거절 후 `requestCount == 0`이 자동 검증된다.
2. 태블릿 결과에서 UTP runner 문제와 앱 기능 결과가 구분되어 있다.
3. 민감 정보 없이 테스트·문서·제품 앱 복구 상태가 기록된다.
