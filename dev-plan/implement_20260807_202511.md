# implement_20260807_202511.md

작성 일시: `2026-08-07 20:25:11 KST`

이 문서는 현재까지 구현된 Android 빠른 채팅·Alpine 작업 모드·MobileAgent 인증/BFF 기반을 기준으로 남은 작업을 한곳에 모으고, 내부 MVP에서 비공개 테스트와 공개 배포로 진행하는 순서를 고정하기 위한 작업 문서다.

## 개발 목적

- 현재 구현과 미구현을 분리해 같은 항목을 반복 분석하지 않게 한다.
- 공개 배포를 막는 외부 결정과 코드로 해결할 수 있는 기능 과제를 분리한다.
- 외부 LLM 운영 검증, Alpine 핵심 사용성, 배포 검증, 장기 기능을 권장 순서대로 닫는다.
- 모든 배포 판정은 문서가 아니라 실제 자동·실기기 증거를 기준으로 fail-closed 처리한다.

## 개발 범위

- 최신 `main` 원격 CI 기준선 확정
- 6개 공개 배포 차단 gate의 owner·입력·증거 확정
- 실제 Provider 계정 기반 OAuth/API/SSE E2E와 BFF 운영 경계 완성
- Alpine 터미널·파일·패키지·개발 도구의 핵심 사용 흐름 완성
- Samsung lifecycle 및 x86_64 emulator 검증
- 통합 앱의 화면 정체성·접근성·상태 복구 정리
- signed AAB/Play test track 및 공개 배포 증거 패키징
- MVP 이후 Alpine 확장 기능의 장기 backlog 유지

## 제외 범위

- 외부 승인·계정·법률 결정을 임의 값으로 대체하지 않는다.
- 실계정 검증 없이 Provider 지원 완료를 선언하지 않는다.
- x86_64 E2E 없이 x86_64를 제품 지원 ABI로 승격하지 않는다.
- PRoot guest `stty`와 `SIGWINCH` 검증 없이 동적 resize를 지원한다고 표시하지 않는다.
- 현재 Android MVP 완료 조건에 iOS 공개 출시를 자동 포함하지 않는다. iOS 출시 여부는 별도 제품 결정으로 남긴다.
- 장기 기능을 공개 배포 필수 gate와 혼합하지 않는다.
