## 목적

`alpine-runtime-background-android`의 foreground-service lease가 terminal/command process의 첫 시작에만
획득되고 마지막 종료에만 해제되는지를 직접 회귀 테스트한다. 이 작업은 제품별 FGS 구현을
`integrated-app` private code로 복제하지 않고 재사용 background 모듈 경계에서 수행한다.

## 안전 경계

- listener는 process ID를 UI·문서·persisted state에 기록하지 않는다.
- process close는 FGS lease만 해제하며 terminal command, Gateway prompt, Runtime을 자동 재실행하지 않는다.
- Android notification 실제 제거는 OEM/Doze 영향이 있어 Samsung 수동 lifecycle matrix와 분리한다.
- reboot, Doze, battery restriction 변경은 수행하지 않는다.

## 작업

- [x] process listener의 start/stop side effect를 unit test로 주입 가능하게 만든다.
- [x] 첫 process 시작/마지막 process 종료, 중첩 terminal·command, FGS start 거부를 회귀 테스트한다.
- [x] background module unit test와 integrated lint/APK를 실행한다.
- [x] Runtime Host 문서과 verification matrix에 자동 검증 경계와 실기기 미검증 범위를 동기화한다.

## 완료 조건

- [x] 한 process 종료가 남은 process의 foreground lease를 해제하지 않는다.
- [x] 마지막 process 종료는 정확히 한 번 FGS stop을 요청한다.
- [x] FGS start rejection은 host stop callback을 정확히 한 번 호출하고 자동 재시작하지 않는다.
- [x] actual Samsung notification/FGS cleanup은 사용자 허가 없는 Doze·background test로 과장하지 않는다.
