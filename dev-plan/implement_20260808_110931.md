## 개발 목적

- 실제 Provider 계정 없이도 HTTP 401/403/404/429/5xx, timeout, malformed SSE, UTF-8 오류와 stream 크기 초과를 결정론적으로 재현한다.
- Android direct Provider와 MobileAgent BFF가 Provider 원문·credential·prompt를 오류 응답과 예외에 노출하지 않도록 fail-closed 경계를 강화한다.
- OAuth callback의 위조·중복 query와 Provider error description이 자동 token 교환 또는 원문 노출로 이어지지 않음을 회귀 테스트로 고정한다.

## 개발 범위

- MobileAgent BFF Provider SSE의 content type, 전체 byte, event byte와 strict UTF-8 검증
- BFF Provider status·timeout·disconnect·malformed SSE 결정론 테스트
- Android Provider SSE parser의 strict UTF-8·전체/event byte 제한 회귀
- Android OpenAI-compatible 오류 body redaction
- OAuth callback error 메시지 redaction과 중복 보안 parameter 거부
- Python·Android unit, lint/build와 Samsung 회귀

## 제외 범위

- 실제 Provider 계정에 의도적으로 429·5xx를 발생시키는 작업
- Provider model catalog·idempotency 계약의 최신 웹 조사
- Redis 다중 BFF replica, 운영 OIDC issuer와 secret manager

- Git commit·Push·원격 CI 실행

## 최종 결과 요약

- MobileAgent BFF에 strict UTF-8 incremental SSE parser, `text/event-stream` 검증과 event 1 MiB·stream 32 MiB 상한을 추가했다.
- BFF status/timeout/disconnect/malformed/oversized fault는 고정 code로 끝나며 stream-open 이후 자동 retry하지 않는다.
- Android direct Provider SSE는 invalid UTF-8과 모든 field/comment를 포함한 event 크기를 fail-closed로 거부한다.
- OpenAI-compatible non-2xx와 invalid success body, OAuth callback Provider error description은 원문 없이 redaction한다.
- OAuth loopback callback은 중복 query parameter와 code+error 동시 입력을 거부하고 다음 정상 callback은 계속 처리한다.
- Python Gateway 102/102, MobileAgent BFF 39/39, Android unit 64/64, Provider unit 25/25가 통과했다.
- Android/Provider/Demo/Integrated Lint와 통합 APK·Test APK build가 통과했다.
- Samsung `SM-S931N`에서 OAuth 저장소 3/3, Provider 12/12, Integrated 10/10으로 총 25/25가 통과했다.
- 최종 `dev.alpine.integrated` APK를 Samsung에 재설치하고 cold start했으며 Demo 앱은 설치하지 않았다.
