## 목적

최근 Runtime package preflight·metadata bounded-total 변경 뒤, GOAL의 필수 자동 검증을 현재 working
tree 기준으로 재실행한다. 이 계획은 새 기능을 성공으로 과장하지 않고 Python/BFF/Android/Samsung과
product-only 설치 상태를 직접 확인해 로컬 증거를 갱신한다.

## 범위

- Python Gateway 전체 unittest와 MobileAgent BFF pytest 실행
- GOAL 지정 Android unit, lint, debug APK/AndroidTest APK build 실행

## 제외 범위

- 실제 Provider 계정/OAuth/API, staging fault proxy, Play/원격 CI
- reboot/Doze/battery restriction/8시간 soak, x86_64 emulator
- PRoot dynamic resize의 유지보수 가능한 upstream/source-level 해법 및 physical acceptance

## 안전 조건

- fake Provider와 credential-free fixture만 사용하고 raw prompt/token/error를 저장하지 않는다.
- Android test APK는 검증 뒤 제거하고 최종 `dev.alpine.integrated`만 설치한다.
- 실패는 숨기지 않고 해당 gate를 `NOT_RUN`/`BLOCKED`로 유지한다.
- commit/push, reboot/Doze/battery 설정 변경은 수행하지 않는다.
