## 개발 목적

완료된 Android OAuth/Host Bridge 기반 위에 실제 앱에서 재사용할 수 있는 Claude·Gemini Provider protocol adapter, Host Bridge 부하 제어, release AAR/Maven 산출 경로를 추가한다. 실제 Provider credential 없이도 protocol 변환과 운영 경계가 자동 테스트되는 상태를 목표로 한다.

## 개발 범위

- OpenAI 공통 request를 Anthropic Messages API 형식으로 변환하고 응답을 공통 형식으로 정규화하는 adapter를 추가한다.
- OpenAI 공통 request를 Gemini generateContent 형식으로 변환하고 응답을 공통 형식으로 정규화하는 adapter를 추가한다.
- ID token의 표시용 claim을 encrypted metadata에 병합하는 token response adapter를 추가한다.
- Host Bridge에 최대 동시 completion 수, overload 429, `Retry-After`, request ID 응답 header를 추가한다.
- release AAR, sources JAR, 프로젝트 내부 Maven repository 산출 경로를 추가한다.
- Android/Python 회귀 테스트와 통합 문서를 갱신한다.

## 제외 범위

- 실제 Provider client id/client secret 발급 및 계정 로그인
- 변경 가능한 Provider endpoint/client id를 라이브러리에 고정
- Gemini GCP project discovery/onboarding
- Kimi Device Authorization Grant와 xAI OIDC discovery
- upstream token delta를 전달하는 SSE streaming
- Alpine rootfs/PRoot 바이너리 다운로드 및 배포
- Android UI, Foreground Service, Play Store 배포

## 후속 우선순위

1. 실제 Provider 등록 정보와 테스트 계정이 준비되면 Claude/Gemini OAuth 및 API physical-device E2E를 수행한다.
2. 장시간 응답의 체감 지연을 줄이기 위해 upstream SSE를 Host Bridge streaming 응답으로 전달한다.
3. Gemini project discovery/onboarding 및 instrumentation test를 추가한다.
4. 실제 Alpine userland 실행이 필요하면 ABI별 PRoot/rootfs 공급·검증·업데이트 정책을 별도 모듈로 설계한다.
