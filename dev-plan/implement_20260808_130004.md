## 목적

Alpine 작업 모드의 Workspace 파일 경계를 실제 Android `content://` provider와 Samsung 계측 테스트로 보강한다. 사용자가 선택하지 않은 외부 파일 권한을 보존하지 않고, import/export·share 과정에서 provider의 원문 오류나 경로 이탈을 노출하지 않는다.

## 범위와 경계

- `:alpine-workspace-android`에 one-shot SAF read/write 및 app-private share file publisher를 둔다.
- `:alpine-runtime-ui-compose`는 선택한 Workspace path만 import/export/share Host action으로 전달한다.
- `:integrated-app`은 Android picker 결과를 bounded transfer하고, cache `FileProvider` URI를 explicit Android share Intent에만 사용한다.
- transfer adapter와 share publisher는 Provider·OAuth token·HostBridge capability·guest 실행 파일을 다루지 않는다.

## 제외 범위

- DocumentsUI와 사용자 share target을 실제로 선택하는 수동 UX, 영속 URI permission, archive/recursive import
- Runtime 설치·guest terminal 실행이 필요한 full import → edit → terminal → export/share smoke
- public release, Provider account E2E, reboot/Doze/process-kill, x86_64 emulator E2E

## 작업

- [x] import `ContentResolver` stream과 export write 실패를 stable `WorkspaceOperationException(IO_FAILED)`로 축소했다.

- [x] read와 share publish에 size cap을 적용하고, share destination의 canonical parent를 확인했다.
