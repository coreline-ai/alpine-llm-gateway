## 개발 목적

- 앱 소유 OpenAI OAuth client registration 없이 공식 App Server가 ChatGPT browser login, localhost
  callback, token refresh, logout을 소유하는 연결을 추가한다.
- 신규 기능은 기존 Codex direct OAuth profile을 대체하지 않고
  **`Codex Agent (ChatGPT 로그인)`**이라는 별도 backend로 제공한다.
- AnyClaw에서 실행 가능성만 참고하고 token 복제, auth bypass, target SDK 하향, runtime `latest`
  설치를 반입하지 않는다.
- feature-off, 회귀 Gate, Samsung 실기기 승인, 명확한 rollback 단위로 배포 위험을 제한한다.

## 개발 범위

- pinned Codex Linux arm64 binary/schema/checksum/license/SBOM artifact pack
- `nativeLibraryDir` direct process와 persistent stdio JSONL App Server client
- managed ChatGPT login/device-code/logout 상태기계와 isolated `CODEX_HOME`
- synthetic Codex Agent connection, contextual thread mapping, turn streaming/interrupt
- 기존 direct/Alpine connection과의 composition, FAST_CHAT-only UI/route
- artifact/source/APK 보안 verifier, 전체 자동 회귀, Samsung login/lifecycle E2E
- Codex-only readiness와 전체 multi-provider release readiness 분리

## 제외 범위

- AnyClaw/OpenClaw 소스 직접 복사, `auth.json` parsing/token 복제, auth-none gateway
- 기존 `ProviderProfile` JSON/direct OAuth/token store/session cache schema 변경
- 기존 Alpine active Runtime session을 App Server와 공유
- App Server failure 시 silent Alpine/direct/proxy fallback
- 사용자 workspace 접근, command approval UI, MCP/apps/plugins, experimental App Server API

## 잔여 리스크 / 추후 계획

- direct static binary의 Android CA/DNS 차이는 system-only CA bundle + authenticated loopback bridge로
  해결했다. 임의 외부 proxy나 PRoot fallback은 추가하지 않으며 bridge 실패는 fail-closed한다.
- 실제 workspace 접근·approval·MCP/apps/plugins는 별도 agent-security 계획 이후에만 진행한다.
- Codex file credential store는 Android Keystore-backed OAuth와 다른 보안 경계다.
- Codex-only PASS 뒤에도 다른 Provider, root license, corresponding source, Play track/destination은 남는다.
- x86_64 emulator는 arm64-only release 필수 조건이 아니다. 다른 ABI 지원 시 새 artifact/test 계획이 필요하다.
