# ARM64 API 26·35 Emulator 호환성 검증 계획

작성 일시: `2026-08-09 13:20:00 KST`

## 목적

GOAL Phase 7은 ARM64 API 26·35 Emulator에서 호환성을 검증하도록 요구한다. 현재 환경에 두 AVD가
실제로 설치되어 있음을 확인했으므로, Samsung 실기기·tablet 증거와 분리된 local emulator matrix를 실행한다.

## 범위

- `Phone_API_35` 및 `TripPilot_API_26`의 ARM64 system image/ABI를 확인한다.
- 각 AVD를 headless로 하나씩 boot하고 integrated-app instrumentation을 실행한다.
- 계측 APK가 제거된 뒤 각 emulator를 종료하고, 로컬 product APK build와 product-only boundary를 유지한다.
- 결과를 GOAL 감사·local verification·readiness evidence에 반영한다.

## 제외 범위

- x86_64 Emulator E2E, Samsung reboot/Doze/battery restriction, physical keyboard·TalkBack gesture manual QA
- real Provider account/OAuth/API 및 Play/원격 CI
- AVD wipe, host system image download/update, user device 설정 변경

## 안전 조건

- emulator는 headless, no-snapshot-save로 실행하며 Samsung의 연결/상태는 건드리지 않는다.
- fake Provider credential-free instrumentation만 사용하고 token, prompt, raw Provider error를 report에 저장하지 않는다.
- app test APK는 Gradle/UTP가 정리한 뒤 AVD를 종료하며, Samsung에는 final integrated product만 남기는 기존
  상태를 변경하지 않는다.
- x86_64 image가 없다는 사실은 ARM64 결과로 대체하지 않으며 해당 release gate는 `BLOCKED`로 유지한다.

## 완료 조건

- [x] API 35와 API 26 ARM64 emulator에서 integrated instrumentation이 PASS한다.
- [x] AVD는 종료되고 Samsung/test product state에 영향을 주지 않는다.
- [x] x86_64 gate와 외부 조건이 ARM64 PASS로 잘못 해제되지 않는다.

## 결과

### ARM64 API 35

- `Phone_API_35`의 system image ABI가 `arm64-v8a`임을 확인했다.
- headless·`-read-only`·`-no-snapshot-save`로 실행한 뒤
  `:integrated-app:connectedDebugAndroidTest`를 수행했고, integrated fake-Provider 계측 **10/10**이
  failure/error/skip 없이 통과했다.

### ARM64 API 26

- `TripPilot_API_26`의 system image ABI가 `arm64-v8a`임을 확인했다.
- 첫 실행에서 Provider 관리 화면이 별도 Activity로 전환된 직후 빈 Compose root를 잠시 관측하는
  instrumentation lifecycle race가 1건 재현됐다. 제품 crash나 Provider 오류가 아닌 test synchronization
  문제였으며, provider-list/chat root가 등록될 때까지 대기하도록 test만 보완했다.
- 보완 뒤 같은 integrated fake-Provider 계측 **10/10**이 failure/error/skip 없이 통과했다.

### 정리·경계

- 두 AVD에서 test/product package를 제거한 뒤 emulator를 종료했다. Samsung·tablet의 연결·설치 상태는
  변경하지 않았다.
- 이후 `:integrated-app:assembleDebugAndroidTest` 및 `:integrated-app:lintDebug`도 통과했다.
- x86_64 system image는 현재 설치되어 있지 않다. ARM64 결과는 x86_64 E2E를 대체하지 않으며
  `X86_64_EMULATOR_UNAVAILABLE` release gate는 계속 `BLOCKED`다.
