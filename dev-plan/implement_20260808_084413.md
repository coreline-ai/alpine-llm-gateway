# implement_20260808_084413.md

작성 일시: `2026-08-08 08:44:13 KST`

이 문서는 통합 앱의 다음 P1인 **빠른 채팅·대화 기록·Assistant 설정 접근성 계약과 한글 IME 흐름**을 보강하기 위한 범위를 고정한다.

## 개발 목적

- TalkBack 사용자가 아이콘 action, 메시지 발신자, 생성 상태와 현재 대화를 문맥 없이도 구분하게 한다.
- 빠른 채팅의 주요 접근성 문구를 한국어 제품 언어로 통일한다.
- 대화 기록 drawer에 명시적 닫기 action을 제공하고 대화별 작업의 대상을 읽을 수 있게 한다.
- 한글 IME의 전송 action과 주요 48dp touch target을 통합 앱 실기기 회귀로 고정한다.
- 기존 Provider·Runtime·first-run·stream·Stop·retry 계약을 변경하지 않는다.

## 개발 범위

- 공통 제품 header와 first-run guide의 heading·장식 요소 semantics
- 빠른 채팅 toolbar, Provider/model 선택, Assistant 설정, composer action의 한국어 접근성 label
- 사용자·AI·오류 메시지의 발신자·상태 단일 semantics
- 대화 기록 drawer의 heading·닫기·대화별 작업·선택 상태 semantics
- Assistant 설정 sheet의 heading과 한국어 shell 문구
- 한글 IME 전송, sender/status semantics, drawer action과 touch target instrumentation
- Samsung `SM-S931N` 실기기 회귀와 문서 동기화

## 제외 범위

- 실제 계정 OAuth/API 호출
- TalkBack 음질·발음·속도에 대한 사람의 청취 판정
