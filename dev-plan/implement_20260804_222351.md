작성 일시: `2026-08-04 22:23:51 KST`

이 문서는 현재 로컬 개발 환경만으로 완료할 수 있는 MobileAgent OAuth·LLM 우선 작업의 범위를 고정하고, 구현이 실제 기기·운영 인프라 영역으로 잘못 확장되지 않도록 하기 위한 작업 문서다.

## 개발 목적

- Android와 iOS가 동일하게 사용하는 Flutter OAuth 계약에 상태 이벤트와 명시적인 protocol capability를 추가한다.
- Flutter Stop이 native socket/task를 즉시 중단한 뒤 BFF 취소 수락 여부를 구분해서 표시하게 한다.
- 재인증 필요 상태와 앱 lifecycle 복귀 시 실행 상태 조정이 Android/iOS에서 같은 계약으로 동작하게 한다.
- 현재 환경에서 자동화할 수 있는 Dart·Kotlin·Swift·BFF 회귀 검증을 완료하고 상위 계획의 상태를 근거에 맞게 갱신한다.

## 개발 범위

- `mobile_agent_auth`의 auth event stream, capability/version negotiation, 재인증 상태 계약
- `mobile_agent_llm_transport`의 request state와 cancel acknowledgment 계약
- Android Kotlin과 iOS Swift native plugin의 동일 동작 구현
- Flutter `AuthController`, `ChatController`, GUI 상태 연결
- BFF cancel 응답 계약과 JWT clock-skew·redaction 회귀 테스트 보강
- Flutter analyze/test, Android unit/build, iOS Simulator build, BFF test 실행

## 제외 범위

- 소유 HTTPS 도메인, App Link, Universal Link와 production OIDC 등록
- 실제 Samsung·iPhone과 OpenAI·Anthropic·xAI 유료 계정 E2E
- Redis·Secret Manager·분산 quota의 production 배포
- Play Internal, TestFlight, 제품 signing과 법률 승인
- Pigeon codegen과 패키지 물리 분리는 이번 계약 안정화 뒤 별도 migration으로 유지한다.
- 대화 본문 영속화는 개인정보·암호화·삭제 정책을 함께 확정해야 하므로 이번 작업에서는 저장소 계약 설계까지만 허용하고 임의 평문 저장은 하지 않는다.

## 잔여 리스크 / 후속 과제

- local native cancel 직후 BFF acknowledgment가 실패하면 서버는 disconnect 감지로 정리해야 하며, 다중 instance 확정 보장은 Redis ownership 구현 전까지 제공할 수 없다.
- 실제 account deletion은 운영 IdP와 개인정보 삭제 주체가 확정될 때 별도 계약으로 구현한다.
- Pigeon migration은 protocol payload가 안정된 뒤 생성 코드와 양 플랫폼 테스트를 함께 적용한다.

## 최종 결과 요약

- Flutter auth protocol version/capability와 redacted auth EventChannel을 Android/iOS에 동일하게 구현했다.
- Stop은 native socket/task를 즉시 중단하고 BFF 결과를 `accepted`, `notActive`, `notRequired`, `unavailable`로 구분한다.
- 앱 resume은 native request가 사라졌을 때 자동 재전송하지 않고 명시적인 실패 상태로 정리한다.
- Flutter auth 14건, transport 7건, app 8건, Android native 6건, BFF 21건과 저장소 unittest 101건이 통과했다.
- Android debug APK와 iOS Simulator app build, local 실제 Keycloak PKCE flow와 OAuth source/artifact scanner가 통과했다.
- 운영 HTTPS domain/signing, 실제 Android/iPhone, 실제 Provider 계정, Redis/Secret Manager와 store 배포는 이번 범위 밖이며 계속 미완료다.
