# implement_20260807_194638.md

작성 일시: `2026-08-07 19:46:38 KST`

이 문서는 MobileAgent 시안에서 확인한 검정·아이보리·라임 시각 언어를 실제 `Alpine AI Workspace`에 이식하는 범위를 고정하고, 기존 빠른 채팅·Alpine 작업 기능을 보존하면서 구현하기 위한 작업 문서다.

## 개발 목적

- `:integrated-app`을 실제 제품 앱으로 유지하면서 승인된 디자인 시안의 시각 체계를 적용한다.
- 빠른 채팅, Provider·모델 선택, 페르소나·스킬, 대화 저장, 중지·재시도와 Alpine Runtime 기능은 그대로 유지한다.
- 연결 전·실행 중·오류·복구 상태의 위계를 명확히 하고 삼성폰에서 잘림과 과밀도를 줄인다.

## 개발 범위

- 공통 Compose 색상·타이포그래피·shape 토큰
- 통합 앱 브랜드 헤더와 빠른 채팅/Alpine 작업 모드 선택기
- 채팅 도구 모음, Provider 선택, 연결 전 안내, 빈 상태, 메시지와 입력창
- Alpine Gateway 상태 카드와 작업 화면 선택기
- 기존 테스트 태그·접근성 설명·기능 callback 보존
- 로컬 빌드·테스트와 Samsung 실기기 화면 검증

## 제외 범위

- `apps/mobile_agent` Flutter 앱의 기능을 통합 앱으로 병합하지 않는다.
- OAuth·Provider·Runtime·Gateway 프로토콜과 저장 형식을 변경하지 않는다.
- 신규 Provider, 모델, 스킬 또는 페르소나를 추가하지 않는다.
- 미리보기용 가짜 연결·성공 상태를 제품 코드에 추가하지 않는다.
- 런처 아이콘과 패키지명을 이번 UI 이식 범위에서 추가 변경하지 않는다.
