# 프로젝트 라이선스 상태

재검사 시점 `2026-08-07` 기준으로 이 저장소 루트에는 프로젝트 전체 코드에 적용되는
`LICENSE` 파일이 없다.

따라서 현재 생성되는 Maven repository와 SDK bundle은 **내부 개발·검증용**이다. 저장소
소유자가 프로젝트 라이선스를 명시하고, 저작권·제3자 고지·source 제공 의무를 검토하기 전에는
공개 Maven repository, 앱 스토어 또는 제3자에게 배포하는 release로 취급하지 않는다.

이 문서는 라이선스를 부여하지 않으며, 제3자 구성요소의 라이선스 의무를 대체하지 않는다.
프로젝트 고유 코드와 OSS payload의 기술적 경계는 `PROJECT_CODE_OSS_BOUNDARY.md`에 기록하지만,
해당 분리 자체가 프로젝트 코드에 배포 허가를 부여하지는 않는다.
