# Alpine AI Workspace 0.3.0

과거 current-state owner authorization에 따라 생성된 signed Android artifact 기록이다.
현재는 **공개 배포물이 아니라 private repository 범위의 내부 검증 산출물**로만 취급한다.

## 주요 기능

- OpenAI 공식 Codex App Server가 소유하는 ChatGPT browser login, callback, credential refresh
- 앱 소유 외부 `client_id`/`client_secret` 없는 Codex Agent 연결
- Samsung ARM64에서 account/model, multi-turn, Stop, restart, lifecycle 검증
- Android system CA와 인증된 loopback CONNECT bridge 기반 static Codex binary 호환
- 기존 direct Provider, Alpine Runtime, workspace와 분리된 fail-closed lifecycle

## 내부 검증 산출물 형태

- Signed APK: 내부 실기기 설치·검증용
- Signed AAB: bundle/split 설치와 서명 검증용; 현재 채널 업로드 계획 없음
- `SHA256SUMS`: artifact 무결성 확인
- `manifest.json`: source commit, signing certificate, readiness 상태
